#  GTA on Python (Ursina Engine)

3D-экшен с открытым миром в стиле Grand Theft Auto, написанный на **Python** с использованием игрового движка **Ursina**.

##  О проекте
Проект создан как пет-проект для изучения 3D-разработки на Python. В игре реализованы базовые механики открытого мира, передвижение персонажа, транспорт и интерфейс.

###  Что уже есть в игре:
-  Открытая 3D-карта города
-  Передвижение и управление камерой от третьего лица
-  Управление транспортом / гонки
-  Пользовательский интерфейс (UI)

---


##  Запуск из исходного кода

Если вы хотите запустить игру через Python или доработать код:

1. Убедитесь, что у вас установлен **Python 3.10+**.
2. Склонируйте репозиторий или скачайте архив с кодом:
   ```bash
   git clone https://github.com
   cd gta-on-python
   ```
3. Установите игровой движок **Ursina**:
   ```bash
   pip install ursina
   ```
4. Запустите главный файл игры:
   ```bash
   python main.py
   ```

---

##  Управление
- **W, A, S, D** — движение / управление машиной
- **Мышь** — обзор камерой
- **Пробел (Space)** — прыжок / ручной тормоз
- **Shift** — ускорение / бег
- **Esc** — выход из игры / пауза
